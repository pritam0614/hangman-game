# 🎯 Hangman Game

A fun and interactive **Hangman Game Web Application** built using Python Flask, HTML, CSS, and JavaScript.

The game allows players to guess words based on different categories and difficulty levels while tracking attempts, hints, scores, and streaks.

## 🚀 Features

- 🎮 Interactive Hangman gameplay
- 📚 Multiple word categories
- 🎚️ Easy, Medium, and Hard difficulty levels
- 💡 Hint system
- ❤️ Attempt tracking
- 🏆 Score calculation
- 🔥 Win streak tracking
- ⌨️ On-screen and physical keyboard support
- 🎨 Modern and responsive user interface
- 📊 Game statistics
- 💾 JSON-based data handling

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- JSON
